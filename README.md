Stock Insight is a full-stack stock research web app that takes any ticker symbol and returns a live quote along with an AI-generated investor report. The backend pulls real-time data from Yahoo Finance, prompts Google's Gemini API for structured analysis, and runs the output through a rule-based scoring engine to produce a clear, factor-based investor report. Built with TypeScript, React, and Node/Express, and developed during Google's AI Professional Certificate program.
